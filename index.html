Personal Google Workspace integration

Hermes Plex

A private personal assistant for the account owner’s email, calendar and tasks.

What the integration does

  • Reads Gmail to help the owner review messages and identify commitments. Gmail access is read-only: it does not authorize sending, deleting or changing messages.
  • Reads Google Calendar and supports owner-requested changes to events on calendars the owner owns.
  • Helps organize personal tasks and prepare owner-requested briefings and reminders using the owner’s chosen private tools.

Private by design of this deployment

The assistant runs separately on owner-controlled equipment using Hermes Agent software. It is an independent personal configuration, not a public SaaS product or an official service of Google or Nous Research.

There is no public sign-up or Google sign-in on this website. This documentation site does not collect Google data, receive OAuth callbacks or host the assistant. Public access to these pages does not provide access to the owner’s account.

Google permissions

The integration requests Gmail read-only access, Calendar read access, and permission to manage events on owned calendars. Technical Calendar permissions include deletion; operationally, changes require the owner’s instructions. General trust does not authorize unrelated changes, invitations or deletion.
